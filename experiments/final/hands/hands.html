Example hands with the mistake measure

Every decision of the agent shows its action probabilities, the expected value Q of each legal action (big blinds, for the whole hand, so a fold is worth minus the chips already invested) and the EV loss: value of the best action minus the value of the agent's own mix. Limit hold'em: against the actual opponent (TAG), estimated by playing every action out against the opponent's likely holdings (Bayes' rule on its actions); a deliberately mixing agent has some EV loss against a fixed opponent by design, so this measures how well it exploits that opponent. Leduc: exact, against the CFR+ equilibrium; the thin bar is the equilibrium's own mix. Each Q assumes both players continue as they actually play, so when the agent's later play is poor even a normally dominated action (folding when a check is free) can come out best. Limit values are estimates (± one standard error; the EV loss is cross-fitted, so it can be slightly negative when the actions are about equally good).
